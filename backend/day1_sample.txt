# HTML Fundamentals

HTML (HyperText Markup Language) is the backbone of every web page. It defines the **structure** and **content** of your website.

## Document Structure

Every HTML page follows this basic structure:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
</body>
</html>
```

## Essential Tags

- **Headings**: `<h1>` through `<h6>` — define content hierarchy
- **Paragraphs**: `<p>` — for text blocks
- **Links**: `<a href="url">` — navigation between pages
- **Images**: `<img src="path" alt="description">` — visual content
- **Lists**: `<ul>`, `<ol>`, `<li>` — organized information
- **Divs & Spans**: `<div>` (block) and `<span>` (inline) — for grouping

## Semantic HTML

Use semantic tags like `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, and `<footer>` to give meaning to your layout. Search engines and screen readers rely on these.
